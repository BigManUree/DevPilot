3. **控制器路径自带 `api/v1` 前缀**（无 setGlobalPrefix）；新模块需显式 import 依赖模块（仅 DatabaseModule 是 @Global）
4. **写迁移前先 grep 既有 schema**（V2 骨架已建多张表，V6 撞表教训）
5. **curl 测 127.0.0.1 需 `NO_PROXY=127.0.0.1,localhost`**（系统代理劫持 502）
6. **Electron 测试**：宿主注入 `ELECTRON_RUN_AS_NODE=1`，子进程 env 必须 delete；打包态原生件须 Electron ABI prebuild（prepare-backend.js 已固化）

8. **logs 表无 message 列**（body_ref 指向文件）——查运行日志用 notifications 表（notify.create 直落库）或读 body_ref 文件
