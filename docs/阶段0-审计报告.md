## 1. 当前产品架构图

```
Electron 桌面壳 (apps/desktop)
 ├─ BackendManager：TCP 探测 37100 → 复用或拉起后端（开发态 node / 打包态 electron-as-node + ABI130）

```

## 9. 主要瓶颈（对照目标）

1. **Agent 工具层只有 3 个原语**——所有"确定性检测"能力（env.detect/runtime.start/log.read）未工具化，Agent 无法自主体检项目
2. **导入与分析耦合薄弱**：分析器输出 services 扁平列表，无组件树、无置信度、无证据链
3. **双轨诊断未统一**：repair-loop（改代码向）与 auto-fixer（启动向）能力重叠，Supervisor 不感知两者
4. **测试体系形同虚设的部分**：4 个空目录、13+ 模块零单测、验收脚本不可 CI 化
5. **工作区有未提交的进行中改动**（autostart 闭环 + V10/V11），与本次升级文件高度重叠
