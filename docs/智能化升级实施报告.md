## 八、已知风险

1. Agent 工具循环依赖 LLM 输出质量：模型输出非法 JSON 时有重试与 finish 兜底，但复杂项目仍可能绕路（实测重规划有效）。
2. `npm install` 白名单允许任意包安装（供应链面仍在）——已受 L2 审批控制，未引入锁文件校验（后续可加 `npm ci`）。
3. WebSocket 前端断线重连为固定 3s，极端网络下可能重复连接。
4. 多版本扫描的常见目录为 Windows 主流安装路径，非标准安装位置可能漏检（PATH/JAVA_HOME 命中的不受影响）。
5. 版本匹配 `~`/`^` 语义针对运行时版本（Java 主版本匹配用 `=` 语义），Gradle wrapper 版本未参与 Maven/Gradle 工具链切换。

## 九、启动与使用

```bash
pnpm install
pnpm dev:backend     # 后端 :37100（自动迁移 v17）
pnpm dev:renderer    # 前端
pnpm dev:desktop     # Electron 壳

cd apps/backend && pnpm test        # 87 用例
node tests/acceptance.mjs           # 验收 22 项（--help 查看参数）
```

使用流程：项目管理 → 导入（任一来源）→ 项目详情「组件树/环境体检」查看档案 → 详情页「启动项目」或 Agent 工作区直接说「帮我启动并验证这个项目」→ 审批中心批准 L2 操作 → 查看执行时间线与健康检查结果 → 「运行档案」留存历史。
