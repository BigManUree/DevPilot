## 二、必须记录的一次事故与修复（重要）

删除 `apps/desktop/resources-backend/` 后，原有打包产物 `pack-opt2` **启动失败**：

```
Error: Cannot find module 'reflect-metadata'
requireStack: ...\pack-opt2\win-unpacked\resources\backend\dist\main.js
```

**根因**：`pnpm deploy` 默认 `isolate` 链接方式产出的是 `.pnpm` 软链；`electron-builder` 复制
`extraResources` 时**不做 dereference**，于是打包产物里的 `resources/backend/node_modules/*`
全是指回本机 `apps/desktop/resources-backend/node_modules/.pnpm/...` 的**绝对软链**。
只要源目录被清理或换机器，产物立刻崩（此前一直没暴露，是因为源目录始终在原地）。

**修复**：
1. `scripts/prepare-backend.js` 的 deploy 加 `--config.node-linker=hoisted`（实测软链数 6206 → 0）；
2. 同脚本新增 fail-closed 校验：产物里只要还剩 1 个符号链接就 `exit 1`，不让它进入打包；
3. 重新 `prepare-backend` → 重新打包到 `apps/desktop/release/win-unpacked/`；
4. **删掉 `resources-backend` 后复测新产物**：后端就绪 1.39s、工作台数据 1.49s（3 轮中位数），可独立运行，证明产物自包含。
