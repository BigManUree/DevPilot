  - `runtime/auto-fixer.service.ts`：计划 `{analysis, commands[], files[], startCommand, port}`；命令白名单（pip/npm/pnpm/yarn/go/cargo/poetry/uv/mvn/gradle/dotnet…）+ 黑名单（rm/del/format/reg/sc/taskkill/icacli/git reset --hard…）；命令 180s 硬超时 + Promise.race；文件写入必须在项目根内；二进制项目禁写源码。
  - `runtime.service.ts`：`waitPort` 15s→25s；端口未就绪但进程已退出 → **判 Failed 而非 Unhealthy**（旧逻辑会把崩溃盖成"运行中但没监听"）。
  - 前端 `components/AutoStart.tsx`：发起 job + 1.5s 轮询 + 步骤时间线（识别/启动/修复/重试/完成/失败）；工作台与项目页**导入成功即自动触发**，项目列表与运行中心各有「自动启动（含修复）」按钮。

- **坑**：① `refine` 里相对 exe 必须 `path.resolve(root, exe)` 再 existsSync（按后端 cwd 解析永远 false）；② venv 判断正则要 `(^|[\\/])`，否则字符串以 `.venv\` 开头匹配不上；③ pip install -r requirements 可能跑十几分钟，必须硬超时否则整条链路挂住。
