## 暂停/恢复修复（用户反馈：暂停后继续任务不能正常执行）
- 根因：run 循环只活在内存。暂停期间 dev watch 重启/异常退出后，DB 停在 Paused/Running 但无活循环；旧 resumeTask 只改 DB 状态 → "恢复了个寂寞"；旧重入守卫按 DB 状态判 409 → 陈旧 Running 连重跑都点不动（截图 115 次调用=多次重跑累积）。
- 修复：liveRuns Set 登记活循环（runTask try/finally 维护）；重入守卫以 liveRuns 为准（DB Running 无活循环=允许自愈重跑）；resumeTask 无活循环时重新拉起 runTask；onModuleInit 把遗留 Running/Preparing 统一降级为 Paused（诚实降级+审计）。
- 测试：重入 409（真实并发 gate）、陈旧 Running 自愈、死循环恢复、活循环暂停→门阻塞→恢复推进 4 个新用例；157/157 + 验收 24/24。
