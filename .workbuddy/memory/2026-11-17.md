## 启动性能优化（打包态冷启动 ≤5s，已达成）

目标：桌面端启动提速到 5s 内。实测基线（旧打包产物 pack-out，warm）：窗口 2.3s 才出现且此前纯白，工作台数据 2.44s 可见。

改造（关键决策）：
- **窗口先行、后端并行**：`backend.ensure()` 提到主进程模块加载期（与 Chromium 初始化并行），`app.whenReady` 先注册 IPC 再立即建窗；托盘/更新检查/审批轮询排到后端就绪后。旧实现 `await backend.ensure()` 后才建窗，把后端 1.9s 变成白屏。
- **渲染层就绪门**：preload 暴露 `backendReady/onBackendReady/startupMark`；`api.ts` 所有请求先 `await whenBackendReady()` 排队，避免启动瞬间 ECONNREFUSED toast。
- **内联启动骨架**（`apps/renderer/index.html`）：窗口一出即有品牌+进度条，React 首渲染时替换；窗口 `backgroundColor` 兜底防白闪。
- 后端：就绪探测 300ms→50ms；`NODE_COMPILE_CACHE`（省 200~300ms）；`undici` 改懒加载（省 ~100ms）。
- **可观测**：`apps/desktop/src/startup-trace.ts` + `apps/backend/src/startup-trace.ts` 共用 0 点写 `<APPDATA>/devpilot/startup-trace.jsonl`；`scripts/startup-bench.mjs`（多轮中位数）、`scripts/startup-ui-bench.mjs`（CDP 轮询 DOM，可跨版本对比「数据可见」）。

结果（pack-opt2 打包态 warm）：窗口 0.45s / 首帧 0.85s / 后端就绪 1.67s / 数据可见 1.78s（CDP 2.19s）；冷缓存首跑 1.9~3.0s 首帧、3.4~4.0s 数据；内存 464→359MB。复用常驻后端时 0.82s 首帧。

验证：后端 jest 173/173；验收干净数据目录 24/24（本机旧库因 `approval.mode=auto` 导致 S5 系列 4 项失败，与改动无关）；渲染层 typecheck 通过；截图 `docs/perf/startup-dashboard-after.png`。

文档：`docs/启动性能优化报告.md`（含逐阶段时间轴、改动清单、backlog：路由级代码分割 / 后端常驻 / 后端单文件打包）。构建产物：`apps/desktop/pack-opt2/win-unpacked/DevPilot.exe`。

坑：宿主 CLI shell 带 `ELECTRON_RUN_AS_NODE=1` 与 `NODE_OPTIONS`，直接跑 Electron 会以 node 模式秒退（报 `app` undefined）；bench 脚本已清这两个变量。`apps/desktop/release`、`pack-opt` 的 app.asar 曾被文件锁占用无法删除（安全删除被拦），已加进 .gitignore。

## 项目清理（A+B 全删）+ 发现并修复打包软链缺陷

按操作者指令删除 A 类（残留/中间产物）与 B 类（可删但失去对照）共 16 项，项目 2.45G → 约 1.46G。
明细与回滚见 `docs/清理清单-20261117.md`。

**事故（重要教训）**：删掉 `apps/desktop/resources-backend` 后，原打包产物 `pack-opt2` 启动即崩：
`Cannot find module 'reflect-metadata'`。根因是 `pnpm deploy` 默认 isolate 产出 `.pnpm` 软链，
而 `electron-builder` 复制 `extraResources` 不 dereference → 打包产物里的 `backend/node_modules/*`
全是指回本机 `resources-backend/node_modules/.pnpm/...` 的**绝对软链**，源目录一删/换机即失效。
此前一直没暴露，只因源目录一直在原地。

修复：`scripts/prepare-backend.js` 的 deploy 加 `--config.node-linker=hoisted`（软链 6206 → 0），
并新增软链 fail-closed 校验（>0 直接 exit 1）；重新 prepare + 打包到 `apps/desktop/release/win-unpacked`，
删掉 resources-backend 后复测：后端就绪 1.53~2.08s、工作台数据 1.64~2.19s，可独立运行。

其他改动：两个 bench 脚本默认 exe 改为「release → pack-opt2 依序取存在者」；README/报告命令同步。
残留：`pack-opt`、`pack-opt2` 各剩一个被文件锁占用的 app.asar（删除挂起），需重启后手动删（命令见清理清单）。
